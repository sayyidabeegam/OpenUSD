# PDF Build (Phase 16)

## Toolchain (default)

Pandoc Markdown → HTML5 → WeasyPrint (CSS Paged Media) → A4 PDF. Graphviz renders diagrams.

Chosen because CSS paged media gives page numbers, running headers, styled callout boxes, and TOC page references without a LaTeX install.

```bash
sudo apt-get install -y pandoc graphviz fonts-dejavu fonts-liberation
.venv/bin/pip install weasyprint
```

Check versions before building: `pandoc --version`, `dot -V`, `.venv/bin/weasyprint --version`. Record them in the master plan.

## Build inputs

- `final/book-order.txt` — ordered list of source files (front matter, parts, chapters, labs, question bank, mock exams, revision, appendices). Generate from the TOC in Phase 16; keep it in sync.
- `final/print.css` — A4 page rules and callout styling (create in Phase 16).
- `final/metadata.yaml` — title, subtitle, author, date, version.

## Build steps

1. Render diagrams: `dot -Tsvg chapters/diagrams/X.dot -o final/build/diagrams/X.svg` for each file.
2. Concatenate with pandoc:
   `pandoc $(cat final/book-order.txt) --metadata-file final/metadata.yaml --toc --toc-depth=2 -s -o final/build/book.html --css final/print.css`
3. PDF: `weasyprint final/build/book.html final/OpenUSD-NCP-OUSD-Study-Book.pdf`
4. Wrap steps 1–3 in `final/build.sh` once working.

## print.css requirements

- `@page { size: A4; margin: 20mm 22mm 24mm 22mm; @bottom-center { content: counter(page); } }`
- Running header with chapter title via `string-set` on `h1`.
- `h1 { page-break-before: always; }`; Part pages centered.
- TOC page numbers via `target-counter(attr(href), page)`.
- Callouts: 1pt black border, gray95 background, bold uppercase label generated by `::before` (EXAM TIP, EXAM TRAP, ...); EXAM TRAP uses a thicker left border so it is distinguishable in grayscale.
- `pre { page-break-inside: avoid; }` for short blocks; `font-size: 8.5pt`; wrap long lines.
- Tables: full borders, header row bold with gray85 background.
- Avoid widows/orphans: `orphans: 3; widows: 3;`.

## Review cycle

After each build:

```
- [ ] Page count recorded in master plan (target 250–400, quality first)
- [ ] TOC entries have correct page numbers
- [ ] Spot-check 10 random pages printed in grayscale (or rendered with a grayscale filter)
- [ ] No code block overflows the margin
- [ ] All diagrams render and captions are numbered
- [ ] Callout labels visible without color
- [ ] Fonts embedded (pdffonts final/*.pdf)
```

Log issues in the master plan and fix in source files, never by editing the PDF.
